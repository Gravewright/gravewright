# Gravewright — Legacy

> [!WARNING]
> **Português (Brasil):** esta é a versão legada do Gravewright. O desenvolvimento
> ativo foi transferido para uma nova base em microkernel, com um núcleo mínimo e
> funcionalidades como campanha, room, renderer, assets e ruleset implementadas
> como módulos independentes e substituíveis. A arquitetura anterior chegou a
> quase 80 capacidades e pontos de extensão, tornando sua manutenção individual
> inviável a longo prazo. Nada deste trabalho será descartado: partes da
> implementação serão reaproveitadas nos novos módulos.
>
> **Español:** esta es la versión legacy de Gravewright. El desarrollo activo se
> trasladó a una nueva base con arquitectura de microkernel, un núcleo mínimo y
> funcionalidades como campaign, room, renderer, assets y ruleset implementadas
> como módulos independientes y sustituibles. La arquitectura anterior llegó a
> casi 80 capacidades y puntos de extensión, lo que hacía inviable mantenerla a
> largo plazo por una sola persona. Nada de este trabajo será descartado: partes
> de la implementación se reutilizarán en los nuevos módulos.
>
> **English:** this is the legacy version of Gravewright. Active development has
> moved to a new microkernel-based codebase with a minimal core and features such
> as campaign, room, renderer, assets, and ruleset implemented as independent,
> replaceable modules. The previous architecture had grown to almost 80
> capabilities and extension points, making long-term maintenance by one person
> impractical. None of this work will be discarded: parts of the implementation
> will be reused in the new modules.

The complete documentation for this version is preserved in
[README-legacy.md](README-legacy.md).
