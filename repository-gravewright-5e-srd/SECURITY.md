# Security

Report security issues privately.

Do not open a public issue for vulnerabilities involving:

- script execution;
- package asset loading;
- package manifest validation bypasses;
- cross-package access;
- storage access;
- content injection;
- XSS or unsafe HTML rendering.

## Scope

This package contains Gravewright ruleset assets, schemas, layouts, and runtime
scripts. Security issues may involve the package itself or Gravewright's SDK
runtime.

## Reporting

Send a private report to the maintainer of the Gravewright project or use the
repository's private security advisory flow if available.

Include:

```text
affected package version
affected Gravewright version
steps to reproduce
expected behavior
actual behavior
impact
suggested fix, if known
```

## Supported versions

Until the package reaches 1.0, only the latest published version is supported.
