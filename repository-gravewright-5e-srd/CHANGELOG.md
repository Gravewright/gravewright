# Changelog

All notable changes to this package should be documented in this file.

This package follows semantic versioning while it remains independently
distributed from Gravewright core.

## 0.3.0 - Standalone package extraction

### Changed

- Extracted the 5e-compatible ruleset package from Gravewright core into a
  standalone package repository.
- Updated package positioning to an unofficial 5e/SRD-compatible framework.
- Updated package compatibility for Gravewright `2.0.0-alpha.0` and SDK 1.
- Updated public capability names to use `sheets.runtime` and `combat.runtime`.

### Notes

- This package does not include official rulebooks, PDFs, artwork, trade dress,
  or a complete proprietary compendium.
- See `NOTICE.md` and `CONTENT_POLICY.md`.
