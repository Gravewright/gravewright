# Support / Como pedir ajuda

## English

Use the repository's public issue or discussion tracker for usage questions, installation problems, and reproducible bugs. Search first, then include:

- what you expected and what happened;
- Gravewright version, Node.js version, operating system, and package manager;
- the exact command and the smallest reproducible module/manifest;
- output from `grave doctor --json` (or `npm run grave -- doctor --json`);
- relevant stack traces with secrets, tokens, paths, and personal data removed.

For lifecycle problems, rerun with `grave run --diagnostic` and share only sanitized lines. Do not report vulnerabilities publicly; follow [SECURITY.md](SECURITY.md). Maintainers do not guarantee response times while the project is pre-1.0.

## Português

Use o rastreador público de issues ou discussões para dúvidas de uso, problemas de instalação e bugs reproduzíveis. Pesquise antes e informe o resultado esperado e o observado, versões, sistema, comando exato, menor reprodução, saída de `grave doctor --json` e stack trace sanitizado.

Para problemas de lifecycle, use `grave run --diagnostic` e compartilhe apenas as linhas necessárias, sem segredos ou dados pessoais. Não publique vulnerabilidades: siga o [SECURITY.md](SECURITY.md). Durante o pré-1.0 não há garantia de prazo de resposta.
