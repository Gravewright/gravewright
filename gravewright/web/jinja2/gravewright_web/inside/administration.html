Server updates

Preview channels may introduce incompatible changes. Keep a full installation backup before updating.

Source installations are updated from the official repository. Back up the database and uploaded files, update the checkout, run uv sync and python manage.py migrate, then restart the server.

Container installations are updated by replacing the image and preserving the data volume.
