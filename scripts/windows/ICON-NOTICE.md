# Gravewright Runner icon

The [Windows icon](gravewright.ico) is a format conversion of Gravewright's existing CSS house mark: the gold square and diagonal used by the application's navigation and welcome screens. It does not introduce a new logo.

Source: [mark.css](../../gravewright/web/static/gravewright_web/css/blocks/mark.css) and [tokens.css](../../gravewright/web/static/gravewright_web/css/tokens.css), rendered by [render_icon.py](render_icon.py). The icon contains 16, 24, 32, 48, 64, 128 and 256 pixel sizes. Colors and gradient come directly from the stylesheet.

Original Gravewright Vue frontend and UI components, copyright 2026 Gravewright contributors. The retained [original notice](../../gravewright/web/static/gravewright_web/ORIGINAL-NOTICE) and [Apache-2.0 license](../../gravewright/web/static/gravewright_web/ORIGINAL-LICENSE) continue to apply to this converted UI asset. The renderer and launcher code follow the project's licensing policy.
