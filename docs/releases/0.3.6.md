# Gravewright 0.3.6

## Realtime delivery and responsiveness

- Process server deliveries independently from player commands and transient cursor, drag and camera samples, while preserving projection ordering.
- Combine redundant queued refreshes and reuse short-lived scene answers with access-change invalidation.
- Avoid repeated chat history, resource subscriptions and mind-map reloads during cursor movement and scene changes.
- Keep presence renewal timing accurate during database contention and handle closing WebSocket transports.

## Database and module requests

- Enable SQLite WAL mode so readers can continue while a writer commits. Set `DATABASE_JOURNAL_MODE=delete` for a database stored on a network filesystem.
- Reuse CSRF tokens with one retry after an explicit token rejection, and renew active module context leases only when needed.
- Add regression coverage, isolated session measurement tools and updated English and Portuguese documentation.

## Português

Esta versão separa a entrega de atualizações dos comandos dos jogadores e das amostras de cursor, arraste e câmera, mantendo a ordem das projeções. Atualizações redundantes são agrupadas e consultas repetidas de cenas, chat, recursos e mapas mentais são reduzidas. A renovação de presença considera a espera pelo banco e o transporte trata conexões em encerramento. O SQLite passa a usar WAL para permitir leituras durante gravações; bancos em sistemas de arquivos de rede devem usar `DATABASE_JOURNAL_MODE=delete`. Requisições de módulos reutilizam tokens CSRF e renovam seus contextos somente quando necessário.

## Download and upgrade

Download `Gravewright-0.3.6-django.zip` and verify its accompanying SHA-256 file. Existing managed installations can use Administration → Updates. For a manual upgrade, stop the Runner, back up and preserve `.env`, `data/` and local extensions, replace application files and rerun the platform installer. No new database migrations are introduced relative to 0.3.5. With WAL enabled, stop all database users before copying database files, or use the application's backup tools; never discard an active database's `-wal` or `-shm` files.

## Download e atualização

Baixe `Gravewright-0.3.6-django.zip` e confira o SHA-256. Use Administração → Atualizações ou pare o Runner, faça backup e preserve `.env`, `data/` e extensões locais, substitua os arquivos da aplicação e execute novamente o instalador. Não há novas migrações em relação à 0.3.5. Com WAL ativo, pare todos os processos que usam o banco antes de copiar seus arquivos ou utilize as ferramentas de backup da aplicação; nunca descarte os arquivos `-wal` ou `-shm` de um banco ativo.
