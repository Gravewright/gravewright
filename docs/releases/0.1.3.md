# Gravewright 0.1.3

Gravewright remains an early development preview. This patch uses the stable
update channel and fixes installation of local module and system ZIP packages.

## Changes

- Fix **Install from ZIP** incorrectly showing **Select a ZIP file.** when a
  valid archive is selected. Capture the form data before the busy state disables
  its inputs, preserving both the file and package kind in the upload.
- Add browser regression coverage for module and system installation, empty-file
  and size-limit validation, and library refresh against the real backend.

## Download and install

Download **Gravewright-0.1.3-django.zip** and its matching **.sha256** file.
Extract the complete ZIP and run **Install Windows.bat**, then start the generated
**Gravewright Runner.bat**. Existing managed 0.1.2 installations can update from
**Administration → Updates**. Keep the optional `.old` copy for rollback.
For older installations, follow the [deployment guide](../en/deployment.md).

The source ZIP includes committed frontend assets and excludes personal data,
credentials, virtual environments and generated launchers.

## Validation

- Playwright marketplace suite, including real local ZIP uploads for both package kinds.
- Django configuration check, locked version metadata and archive integrity.

## Português (Brasil)

um arquivo válido selecionado. Os dados agora são capturados antes de desabilitar
os campos durante a instalação. Os testes com Playwright cobrem módulos, sistemas,
validação de tamanho e atualização da biblioteca.

Baixe **Gravewright-0.1.3-django.zip** e o arquivo **.sha256** correspondente.
Extraia o ZIP completo, execute **Install Windows.bat** e inicie pelo
**Gravewright Runner.bat** gerado. Instalações gerenciadas na versão 0.1.2 podem
usar **Administração → Atualizações**. Mantenha a cópia `.old` para rollback.
Para instalações anteriores, consulte o [guia de implantação](../pt-BR/deployment.md).
