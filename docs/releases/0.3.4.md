# Gravewright 0.3.4

## Table controls and Firefox

- Stopping combat clears participants, turn history and encounter state.
- Restore WebGL rendering after context loss, initialize fallback textures and avoid redundant context probes. Adjust CSP fallback for Firefox source loading while retaining explicit object/frame restrictions.
- Restrict selection to the active layer; add configurable F1–F8 layer and scene shortcuts.
- Group secondary dock actions under Panels and align chat window controls.

## Organization and appearance

- Fix actor subfolder creation and reveal newly created subfolders in Actors, Items, Journals and Scenes, including after reload.
- Give blank maps the grid, measurement, scale, folder and visibility options of image maps.
- Show only the active RPG system in table Extensions.
- Add Classic, Ocean, Forest and Amethyst interface themes with browser persistence.
- Expand English and Portuguese documentation and Firefox regression scenarios.

The Savage Worlds sheet improvements ship separately in system package 0.1.4. The unfinished native Rust launcher is excluded; existing installers remain available.

## Português

Parar o combate limpa os participantes e o estado do encontro. Esta versão corrige a criação e a exibição de subpastas, melhora o comportamento no Firefox, limita a seleção à camada ativa, adiciona atalhos F1–F8, reorganiza a barra de ferramentas e os controles do chat, amplia as opções dos mapas vazios e acrescenta quatro temas. Extensões mostra somente o sistema ativo da mesa. As fichas Savage Worlds são distribuídas separadamente no pacote 0.1.4. O launcher Rust incompleto não faz parte desta versão.

## Download and upgrade

Download `Gravewright-0.3.4-django.zip` and verify its accompanying SHA-256 file. Existing managed installations can use Administration → Updates. For a manual upgrade, stop the Runner, back up and preserve `.env`, `data/` and local extensions, replace application files and rerun the platform installer. No new database migrations are introduced relative to 0.3.3.

## Download e atualização

Baixe `Gravewright-0.3.4-django.zip` e confira o SHA-256. Use Administração → Atualizações ou pare o Runner, faça backup e preserve `.env`, `data/` e extensões locais, substitua os arquivos da aplicação e execute novamente o instalador. Não há novas migrações em relação à 0.3.3.
