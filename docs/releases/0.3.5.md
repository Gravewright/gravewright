# Gravewright 0.3.5

## Realtime reliability

- Improve socket delivery with bounded message lanes, post-commit notifications and recipient-specific updates.
- Recover commands from temporary database contention and maintain presence leases.
- Improve authorization caching and reduce redundant realtime refresh work.

## Chat and compendiums

- Preserve scene context for module chat messages.
- Allow authorized players to access native item and spell compendium packs.
- Update regression coverage and English and Portuguese architecture documentation.

## Português

Esta versão melhora a entrega de mensagens em tempo real, a recuperação de comandos durante contenção temporária do banco de dados e a manutenção da presença. As notificações são enviadas após a confirmação das transações, com atualizações específicas por destinatário e menos trabalho redundante de atualização e autorização. O chat de módulos preserva o contexto da cena e jogadores autorizados podem acessar os compêndios nativos de itens e magias.

## Download and upgrade

Download `Gravewright-0.3.5-django.zip` and verify its accompanying SHA-256 file. Existing managed installations can use Administration → Updates. For a manual upgrade, stop the Runner, back up and preserve `.env`, `data/` and local extensions, replace application files and rerun the platform installer. This release adds a campaign revision database migration, applied by the updater or platform installer.

## Download e atualização

Baixe `Gravewright-0.3.5-django.zip` e confira o SHA-256. Use Administração → Atualizações ou pare o Runner, faça backup e preserve `.env`, `data/` e extensões locais, substitua os arquivos da aplicação e execute novamente o instalador. Esta versão adiciona uma migração de revisão de campanha, aplicada pelo atualizador ou instalador da plataforma.
