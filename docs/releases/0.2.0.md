# Gravewright 0.2.0 — Alpha

Gravewright 0.2.0 remains an early development preview. This release gathers the
changes since 0.1.3 and provides the host translation API documented by Translator
0.1.2. API/SDK and module versions are independent of the VTT release number.

## Changes

- Independent character sheets for third-party systems, without inheriting the
  PDF System's tabs; consistent window controls, compact dialogs and Escape closing.
- PDF System combat integration, token portraits, green current-turn and yellow
  next-turn pulses, resource bars, condition descriptions and duration controls.
- Permission-aware table search, a toolbar search action and compendium visibility
  based on available content.
- GM token and image support layers, with GM access across editing layers.
- Scene preparation and preloading, revised scene forms and grid calibration.
- Map links for journals and quests, linked quest creation and compact quest boards
  with an empty state.
- Revised icons, toolbar colors, CSS spacing and table preferences; language changes
  preserve the table URL. Condition descriptions appear on token and HUD hover.
- Safer module/system removal with affected-table confirmation and unlinking;
  table extensions expose activation and supported customization controls.
- Segmented ruler measurements using Ctrl and removal of lower-left helper text.
- Reviewed Portuguese and Spanish controls and correct initial loading of native
  translations. User-authored content retains its original text.
- `context.i18n` / `context.api.i18n` for modules and systems: private catalogs,
  named/numbered parameters, locale fallback, number formatting and lifetime cleanup.
- Runner configuration, update and rendering fixes accumulated since 0.1.3.

## Download and install

Use **Gravewright-0.2.0-django.zip** and its matching **.sha256** file. The ZIP
contains the application and built frontend assets. Translator is a separate
Marketplace package; install or update it to **0.1.2** for the reviewed catalogs
and complete integration documentation.

For a new Windows installation, extract the complete ZIP, run **Install Windows.bat**
and start the generated **Gravewright Runner.bat**. For an existing managed
installation, use **Administration → Updates** once this release is published.
Keep a backup of your database, media and configuration before upgrading; retain
the optional `.old` copy for rollback. See the [deployment guide](../en/deployment.md).

The identifier `0.2.0` follows the existing `stable` update-channel convention;
the project still has Alpha development status. No test system, local secrets,
campaign data, dependencies or generated machine-specific launchers belong in
the release ZIP.

## Validation

- 421 Django tests passed using disposable on-disk SQLite and the standard password
  hashers, including concurrent setup/join and public API notification checks.
- 30 module/effect JavaScript tests and 66 map model tests passed.
- Playwright exercised an extracted copy of the actual release ZIP with Translator
  0.1.2 in English, Brazilian Portuguese and Spanish; no browser errors occurred.
- Locked dependency metadata, Windows launcher source checks, generated API contract,
  translation audit and ZIP integrity passed.

## Português (Brasil)

A versão **0.2.0 Alpha** reúne as melhorias desde a 0.1.3:

- Fichas independentes para sistemas de terceiros, janelas e modais padronizados
  e fechamento pelo Escape.
- Combate no PDF System, retratos dos tokens, discos de turno verde e amarelo,
  barras de recursos e descrições/duração de condições.
- Busca respeitando permissões, acesso pela barra e compêndios exibidos conforme
  o conteúdo disponível.
- Camadas de GM para tokens e imagens, acessíveis pelo mestre entre as camadas.
- Preparação e pré-carregamento de cenas, formulário revisado e calibração da grade.
- Vínculos de diários e missões no mapa, criação de missão vinculada ao quadro,
  apresentação compacta e estado vazio.
- Ícones, cores da barra, espaçamentos e preferências revisados; mudança de idioma
  preserva a mesa. Descrições de condições aparecem ao passar o mouse no token e HUD.
- Remoção de módulos/sistemas com aviso das mesas afetadas e desvinculação;
  extensões da mesa com ativação e personalização quando disponível.
- Régua com segmentos ao segurar Ctrl e remoção de dicas no canto inferior esquerdo.
- Revisão de português e espanhol e correção do carregamento inicial das traduções.
  Conteúdo criado pelos usuários é preservado.
- API de tradução para módulos/sistemas com catálogos privados, parâmetros,
  fallback de idioma, números e limpeza automática ao encerrar o contexto.
- Correções acumuladas de configuração do Runner, atualizações e renderização.

Baixe **Gravewright-0.2.0-django.zip** e seu **.sha256**. O Translator é instalado
separadamente pelo Marketplace; use a versão **0.1.2** para os catálogos revisados
e documentação completa da integração.

Em uma instalação nova no Windows, extraia o ZIP completo, execute
**Install Windows.bat** e inicie pelo **Gravewright Runner.bat** gerado.
Instalações gerenciadas podem usar **Administração → Atualizações** após a
publicação. Faça backup do banco, arquivos e configuração e mantenha a cópia
opcional `.old` para rollback. Veja o [guia de implantação](../pt-BR/deployment.md).

A numeração `0.2.0` mantém o canal de atualização `stable` conforme a convenção
existente; o estágio do projeto continua Alpha. O pacote exclui o sistema de teste,
segredos, mesas locais, dependências e launchers específicos desta máquina.

Validação: 421 testes Django e 96 testes JavaScript aprovados. O Playwright testou
uma cópia extraída do ZIP com Translator 0.1.2 nos três idiomas, sem erros de
navegador. Lockfile, launcher Windows, contrato gerado da API, auditoria de
traduções e integridade do ZIP também foram verificados.
