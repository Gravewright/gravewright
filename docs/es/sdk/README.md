# SDK 1 de Gravewright

SDK 1 es el contrato público estable para packages. La fuente estructural
canónica es [`gravewright-sdk-1.json`](../../sdk/_data/gravewright-sdk-1.json),
con declaraciones para editores en
[`gravewright-sdk-1.d.ts`](../../sdk/gravewright-sdk-1.d.ts).

Consulte el [inicio rápido](quick-start.md), la
[referencia de métodos](method-reference.md), la
[referencia de DTOs](dto-reference.md), el [índice estructural](contract-index.md),
las [capabilities](capabilities.md), el [manifest](manifest.md) y
[seguridad](security.md). Los nombres de methods, capabilities, DTOs, events y
error codes no se traducen.
